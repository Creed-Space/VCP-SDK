# Archived host integrations

These files are historical Creed Space and Rewind host adapters. They are not
part of the portable VCP SDK package, test gate, or compatibility promise.

The host repositories own active integration tests. A future extraction must
define a public adapter interface, fixtures, and dependency boundary before any
of these files return to `python/src` or `python/tests`.

Historical adapter source formerly under `integrations/` and host-specific
Markdown formerly under `docs/` were archived on 2026-08-13. They depend on
packages outside VCP-SDK and are not imported, tested, or distributed.
